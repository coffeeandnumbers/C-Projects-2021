# University C++ Projects 2020-2021

**deque.cpp**
Implementation of a deque with custom random-access iterators.

**geometry.cpp**
Implementation of 2D geometry with points, lines, geometric shapes and transformations.

**matrix.cpp**
Implementation of arbitrary-precision integers, rational, finite-field arithmetic, and matrices.

**tuple.cpp**
Metaprogramming implementation of tuple.

**unordered_map.cpp**
Implementation of unordered map with a custom list and fast fixed-size allocators.
